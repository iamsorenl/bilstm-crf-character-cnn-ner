# bilstm-crf-character-cnn-ner
🔬 Biomedical NER with BiLSTM-CRF This project implements a BiLSTM-CRF model with character-level CNN embeddings for biomedical named entity recognition on the BioNLP/NLPBA 2004 dataset. It identifies entities like DNA, RNA, proteins, cell lines, and cell types using PyTorch and Viterbi decoding.
